# The Glow Edit

A complete static starter website for a beauty & skincare affiliate brand.

## Files
- `index.html` — homepage
- `guides.html` — beauty guides
- `about.html` — about page
- `contact.html` — contact page
- `disclosure.html` — affiliate disclosure
- `privacy.html` — privacy template
- `style.css` — responsive design
- `script.js` — mobile menu + demo newsletter interaction

## Before publishing
1. Replace the placeholder Amazon links in `index.html` with your real affiliate links.
2. Replace `hello@theglowedit.example` with your real contact email.
3. Customize the privacy policy for the services you actually use.
4. Connect the newsletter form to an email provider if you want subscriptions.
5. Check the name/domain/trademark availability before investing in the brand.
6. Review affiliate-network rules and applicable advertising/disclosure requirements.

## Free hosting
This static site can be hosted on GitHub Pages or Netlify at no hosting cost. A custom domain is optional and usually costs extra.
